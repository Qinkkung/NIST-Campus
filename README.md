# NIST-Campus

ระบบต้นแบบสำหรับจัดการการใช้บริการภายในมหาวิทยาลัยด้วย **NIST Token บน BSC Testnet** และ **Trust Score** เพื่อใช้ประกอบการทดลองแนวคิดการจองทรัพยากรของมหาวิทยาลัย

## ลิงก์ระบบ

- **Backend API (Render):** https://nist-campus.onrender.com/api
- **Source code:** https://github.com/Qinkkung/NIST-Campus

> หมายเหตุ: ใน README ฉบับเดิมไม่มี URL สำหรับหน้าเว็บที่เปิดใช้งานโดยตรง จึงยังไม่ได้ใส่ลิงก์หน้าเว็บเพื่อหลีกเลี่ยงการระบุ URL ผิด หากมี URL หน้าเว็บที่ Deploy ไว้แล้ว ให้เพิ่มไว้ในหัวข้อนี้

## ความสามารถหลัก

- เชื่อมต่อกระเป๋า MetaMask
- อ่านยอด NIST Token จาก Blockchain
- รับรางวัลปฐมนิเทศ 20 NIST โดย Reward Wallet เป็นผู้ยืนยันการโอนจริง และเพิ่ม Trust Score 5 คะแนน
- ทดลองจองบริการ/ห้อง โดยโอน 50 NIST ผ่าน MetaMask
- ดูข้อมูลการจองและประวัติธุรกรรม
- เมื่อยกเลิกการจอง จะไม่คืน NIST ที่จ่ายไป และหัก Trust Score 2 คะแนน ตามกติกาของต้นแบบ

## วิธีใช้งานระบบ

### 1. เตรียมกระเป๋าและเครือข่าย

1. เปิดเว็บระบบด้วยเบราว์เซอร์ที่ติดตั้ง **MetaMask Extension**
2. เลือกเครือข่าย **BNB Smart Chain Testnet (BSC Testnet)** ใน MetaMask (Chain ID: `97`)
3. ตรวจสอบว่ากระเป๋าที่ใช้มี NIST Token สำหรับทดลอง และมีเหรียญทดสอบสำหรับค่าธรรมเนียมเครือข่าย (Gas) หากธุรกรรมต้องใช้
4. กด **Connect** บนหน้าเว็บ แล้วอนุญาตให้เชื่อมต่อ MetaMask

> ใช้กระเป๋าทดสอบเท่านั้น ห้ามเปิดเผย Seed Phrase หรือ Private Key ให้ผู้อื่น

### 2. ตรวจสอบ Dashboard

หลังเชื่อมต่อกระเป๋า ให้ตรวจสอบที่อยู่ Wallet และยอด NIST ที่แสดง ยอด NIST อ่านจาก Blockchain ส่วน Trust Score เป็นคะแนนที่ Backend ของต้นแบบจัดเก็บแยกจาก Token

### 3. รับรางวัลปฐมนิเทศ 20 NIST

การสาธิตนี้ใช้ 2 กระเป๋า ได้แก่ **Student Wallet** (กระเป๋านิสิตผู้รับ) และ **Reward Wallet** (กระเป๋าสำหรับแจก Token)

1. เชื่อมต่อเว็บด้วย Student Wallet
2. กดปุ่ม **รับ 20 NIST + 5 Trust Score** เพื่อให้ระบบบันทึกกระเป๋าผู้รับ
3. สลับ MetaMask ไปยัง Reward Wallet แล้วกด Connect อีกครั้ง
4. กดปุ่มรับรางวัลอีกครั้ง และตรวจสอบรายละเอียดธุรกรรมใน MetaMask
5. ตรวจสอบที่อยู่ผู้รับและจำนวน **20 NIST** ก่อนยืนยันการโอน
6. รอให้ธุรกรรมได้รับการยืนยันบน Blockchain
7. สลับกลับไปยัง Student Wallet แล้ว Connect ใหม่ เพื่อตรวจสอบยอด Token และ Trust Score ที่อัปเดต

Reward Wallet ต้องมี NIST เพียงพอสำหรับการโอน และมีเหรียญสำหรับค่าธรรมเนียมเครือข่ายตามที่ MetaMask กำหนด การจำกระเป๋าผู้รับในขั้นตอนนี้อาศัยเบราว์เซอร์เดิม จึงควรทำทั้งสองขั้นตอนบนเบราว์เซอร์และอุปกรณ์เดียวกัน

### 4. ทดลองจองบริการ/ห้อง

1. เชื่อมต่อด้วย Student Wallet
2. เลือกบริการหรือห้องที่ต้องการจอง แล้วดำเนินการตามแบบฟอร์มบนหน้าเว็บ
3. ตรวจสอบธุรกรรมใน MetaMask โดยต้นแบบกำหนดค่าจอง **50 NIST**
4. ยืนยันธุรกรรมและรอ Blockchain ยืนยัน
5. กลับมาตรวจสอบสถานะการจองและยอด NIST

การโอน Token ต้องได้รับการยืนยันจากกระเป๋าที่ทำรายการก่อน ระบบจึงดำเนินการบันทึกผลการทำรายการต่อ

### 5. ยกเลิกการจอง

เลือกการจองที่ต้องการยกเลิกและใช้คำสั่งยกเลิกในระบบ ตามกติกาของต้นแบบ **NIST ที่จ่ายไปจะไม่ถูกคืน และ Trust Score จะถูกหัก 2 คะแนน** โปรดตรวจสอบรายการก่อนยืนยันการยกเลิก

### 6. ตรวจสอบประวัติธุรกรรม

ใช้ส่วนประวัติธุรกรรมในระบบหรือดู Activity ใน MetaMask เพื่อตรวจสอบสถานะและ Transaction Hash ของรายการที่ทำบน Blockchain หากต้องการตรวจสอบบน Block Explorer ให้เลือกเครือข่าย BSC Testnet และค้นหาด้วย Transaction Hash

## ข้อควรทราบ

- โปรเจกต์นี้เป็น **Prototype สำหรับการสาธิตและการศึกษา** ไม่ใช่ระบบบริการจริงของมหาวิทยาลัย
- NIST Token เป็น Token บน Blockchain ส่วน Trust Score เป็นคะแนนที่ Backend จัดการ ไม่ใช่ Token
- การรับรางวัลต้องสลับจาก Student Wallet ไป Reward Wallet เพื่อเซ็นธุรกรรม จึงควรตรวจสอบ Account ที่เชื่อมต่ออยู่ทุกครั้ง
- Backend ของต้นแบบอาจเก็บข้อมูลไว้ในหน่วยความจำ ดังนั้นข้อมูลบางอย่าง เช่น คะแนนหรือสถานะ อาจถูกรีเซ็ตเมื่อบริการเริ่มต้นใหม่ ไม่ควรใช้เป็นฐานข้อมูลสำหรับการใช้งานจริง
- ก่อนยืนยันธุรกรรม ให้ตรวจสอบเครือข่าย ที่อยู่กระเป๋าผู้รับ และจำนวน Token ทุกครั้ง
